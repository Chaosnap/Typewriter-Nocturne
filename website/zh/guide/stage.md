# 舞台与画质

你的 Shell 打在立于打字机中的纸上。文字永远停在压纸杆上方，所以打字机不会遮住任何字符；窗口可以随意调整大小，终端会像在普通窗口里一样重新适配纸张。

## 打字机

模型采用基于物理的材质、柔和阴影，以及用于反射的暗色书房环境：橡胶压纸滚筒配镀铬端盖和胶木旋钮、回车手柄、带滚花滚轮的压纸杆、清漆珐琅机身、机身上的色带卷轴、刻有与终端列数一一对应刻度的缎面镍标尺，以及金箔铭牌。

字头沿抛光导轨滑行，下方齿条每一齿对应一列，所以擒纵机构每次击键恰好推动字头前进一齿：先加速，再被下一齿挡住并轻微回弹；由于它挂在导轨上，停下或撞到边距时会轻轻摆动。每次击键都会把字头抛向滚筒，并抬起色带。字头跟随当前终端的光标；在 Vim、htop 这类全屏程序里，它会跟到程序放光标的位置。

## 画质（Quality）

| 画质 | 绘制内容 |
| --- | --- |
| **Auto（自动，默认）** | 有真实 GPU 时绘制完整舞台；没有可用 GPU 时（虚拟机、远程桌面、部分服务器）只保留纸张、打字墨迹和声音，保证终端流畅 |
| **High** | 在任何 GPU 上绘制完整舞台，全分辨率柔和阴影 |
| **Medium** | 较锐利的阴影，最高 1.5 倍分辨率 |
| **Low** | 不画阴影，1 倍分辨率 |

着色器在后台编译，窗口永远不用等待；编译完成后打字机才会出现。如果动画变慢，舞台会自动切换为不带动画的简化绘制。Studio 最后一栏的底部会显示当前的绘制方式。

## 专注模式与安静模式

「Focus mode（专注模式）」隐藏打字机、灯光和所有装饰，只留下纸张。Studio 里的「All visual effects」会关闭灯光、光晕、打字墨迹和动画，但保留布局。如果想要和 Hyper 完全一样的终端外观，在 `nocturne.json` 里设置 `"theme": "classic"`。
