# 更新日志

每个版本都由 GitHub Actions 构建、测试和打包；安装包和 SHA-256 校验值在 [Releases](https://github.com/Chaosnap/Typewriter-Nocturne/releases) 页面。目前所有版本都是 alpha 版：安装包没有代码签名，请参阅 [docs/INSTALL.md](https://github.com/Chaosnap/Typewriter-Nocturne/blob/main/docs/INSTALL.md)。英文原文见 [CHANGELOG.md](https://github.com/Chaosnap/Typewriter-Nocturne/blob/main/CHANGELOG.md)。

## 0.1.0-alpha.3

### 房间

- **拉绳**：更长、更细长，直接从顶部边缘垂下，上方不再有底座。流苏更精致（雕花铃形罩、金环和一圈散开的丝穗），每一根丝线都是一个独立的单摆，比绳子稍慢半拍地摆动。Studio 的 Lamp 一栏里「Pull cord」可以显示或隐藏它；专注模式下永远不会出现。
- **回形针滚动条**：一枚夹在纸张右边缘的钢丝回形针，后面的环从纸边露出来。它滑向当前滚动位置，移动时会倾斜，可以拖动。可选银、黄铜、金或黑色；也可以改用透明度和宽度可调的半透明白色滚动条，或系统滚动条。用滚轮和触控板滚动时回形针同样跟随。
- **压纸杆滚轮**：双击左边的滚轮卷到顶部，双击右边的卷到底部，滚筒也会随之转动。
- **墨水选区**：选中的文字下面是一层柔和、羽化的淡墨，每个被选进来的字会像墨水落进水里一样晕散再重新成形。选「Classic」则保留 xterm 的选区方框。选择和复制的行为不变。
- **灯泡附近的光更柔和**：光锥在灯旁柔和地展开，光最亮的地方纸面纹理会被压平，灯下的文字和别处一样清晰。

### 专注模式

- 背景可以单独设置：当前纸张、深色纸张或任意颜色（墨色会自动变浅或变深）。
- 纸张效果（纹理、打字墨迹、墨水选区）和台灯的光可以分别保留或关闭。
- 拉绳永远不会出现。

### 印刷机与档案

- **Command（上一条命令）**：新的来源，把你运行的上一条命令连同输出一起印出来。
- Selection、Screen 和 Command 不再显示代码片段输入框，而是显示将要印的行数和开头几行，并在打印时重新读取终端。
- **纸张、火漆与字体**：五种纸（条纹纸、棉纸、犊皮纸、羊皮纸、夜间纸），六种火漆（深红、牛血红、黑、金、祖母绿、宝石蓝，各配一条丝带），压进火漆的一到两个字母，纹章（新月、玫瑰、羽毛笔或不要），丝带可开关，正文字体（Courier Prime、EB Garamond、Cormorant Garamond、IBM Plex Mono、终端字体或任何已安装字体），以及 “— set at the typewriter, by …” 中你自己的名字。火漆预览实时显示将要盖下的样子，每张诗笺都保存打印时的样式。
- 更精致的火漆：隆起的光亮边缘、溢出的蜡滴、珠点边框、压印的纹章和字母，以及蜡面的颗粒与高光。
- **档案**：可以给诗笺改名；可以勾选多张（或全选）一次删除。

## 0.1.0-alpha.2

- **输入法**：拼音、假名、韩文在组合输入时就会击键，上屏时是一记有力的双击；候选框、上屏和 Shell 收到的内容都不受影响。
- **音效**：更丰富的合成打字杆、空格键、回车时的字车回位、用 ↑/↓ 翻历史时的滚筒棘轮、←/→ 的擒纵声、制表器，按字头位置立体声定位。
- **字体**：Nerd Font 预设、任意已安装字体，并内置 Symbols Nerd Font，每种字体都能显示图标。
- **台灯**：亮度、光束角度和朝向可调；左上角剧院帷幕式的拉绳可以开关台灯。
- **印刷机与档案**：把代码片段、选中内容或屏幕印成十四行诗式的诗笺并盖上火漆；保存在本地、导出 PNG 或复制文字。
- GitHub Pages 上的中英文文档网站。

## 0.1.0-alpha.1

- 首个版本。Hyper 的终端（xterm.js、node-pty）运行你真实的 Shell，外面是一张书桌：字头按擒纵物理跟随光标的 3D 打字机、由基于物理的台灯照亮的纸张、三个主题和六种纸张、打字墨迹、合成的打字机声音、Nocturne Studio、专注模式，以及在没有可用 GPU 时保持终端流畅的自动画质。
- 云端构建的 macOS（arm64、x64）、Windows x64 和 Linux x64（AppImage、DEB）安装包。
