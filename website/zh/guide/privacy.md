# 隐私与安全

- **从不触碰终端数据流。** 效果层从不订阅、延迟、缓冲或改写发往 Shell 或来自 Shell 的内容。按键只被被动观察，不会被拦截或修改，所以快捷键、粘贴、括号粘贴和输入法都和 Hyper 一样工作。
- **隐藏输入始终隐藏。** 打字墨迹只会画在终端已经显示出来的字符上；不回显的密码永远不会出现在任何效果里。
- **只有打印时才读取终端文字。** 只有在印刷机里选择「Selection」或「Screen」时，才会读取选中内容或屏幕。诗笺只保存在你的电脑上，不会上传到任何地方。
- **一切都经过校验。** 设置和诗笺在使用或写入前都会校验；档案里的文件名由应用生成，从不取自输入；导出的图片必须是 PNG。主题不包含任何代码。
- **不改动你的系统。** 从不修改 Shell 启动文件，也不会读取或修改已有的 Hyper 安装。
- **保持 Hyper 原有的 Electron 安全边界。** 内置字体只在构建时下载，固定到指定版本并校验哈希；不会在你的电脑上下载任何东西。
