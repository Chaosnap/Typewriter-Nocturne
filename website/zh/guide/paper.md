# 纸与墨

纸张与主题相互独立，终端的配色由纸张决定。每种纸都保证墨色对比度高于 7:1、浅墨高于 4.5:1、所有 ANSI 颜色高于 3:1，这些都由项目的测试检查。

| 纸张 | 特点 |
| --- | --- |
| Cotton（棉纸，默认） | 柔软、略带褶皱的布浆纸 |
| Laid（条纹纸） | 横向细密的条纹，纵向的链线 |
| Linen（亚麻纸） | 编织状的交叉纹理与纱结 |
| Onionskin（葱皮纸） | 轻薄光滑，几乎没有纹理 |
| Parchment（羊皮纸） | 斑驳陈旧，带霉点、水渍与折痕 |
| Night（夜间纸） | 夜间使用的深色纸，配浅色墨水 |

## 纹理与打字墨迹

「Texture depth」控制纸面纹理的深浅，以及纤维对光的反应强弱。「Type impression」控制你打出的字如何落下：刚落下的一瞬间字迹更重、墨水微微晕开，随后沉淀为普通印刷字。墨迹只会画在终端已经显示出来的字符上，所以密码等隐藏输入永远不会出现在效果里。
