# 台灯与拉绳

## 拉一下绳子

一根细长的绳子从房间顶部边缘垂下来，像剧院帷幕的拉绳：深红丝绳缠着金线，末端是一枚按传统流苏工艺做成的流苏：鎏金小珠、缠着深红丝线并系着金线的梨形流苏头、头底一圈金色绞绳，下面是稍窄一些的细丝穗，中间收腰、末端散开，像双曲线一样。往下拉就能开关台灯：拉动时绳子会伸长，拉到底时开关“咔哒”一声，松手后绳子回弹、摆动；流苏的每一根丝线都各自摆动，比绳子稍慢半拍。点击绳子，或在它获得键盘焦点时按 <kbd>Enter</kbd>，也会拉一下。用 View 菜单或快捷键开关台灯时，绳子也会轻轻晃动。

Studio 的 Lamp 一栏里的「Pull cord」可以显示或隐藏拉绳。专注模式下拉绳永远不会出现。

## 灯光

每个主题有自己的光源：

| 主题 | 光源 |
| --- | --- |
| Paper & Ink | 字架上的小灯，从字头处向纸面上方照射 |
| Midnight Study | 纸张右上方的台灯 |
| Moonlit Poetry | 穿过窗框洒落的月光 |

灯光遵循物理规律：照度随距离平方衰减，符合朗伯余弦定律，光锥边缘柔和；月光以平行光入射，并投下窗棂的影子。纸张按「反照率 × 照度」着色，所以墨色和纸色一起变亮变暗。远离灯光处房间会让纸面变暗，但墨色对比度永远不会低于 4.5:1。台灯把纸当作平面来照亮，光斑因此平滑干净（低角度的光若按每根纤维投影，会在纸上洒满黑点）；你选的纸在光里保持自己的纹理，只在灯泡下略微安静一些，所以灯正下方的文字和其他地方一样清晰。

在 Paper & Ink 主题下，光束是一个干净的三角形：尖端在字头，沿纸面向上展开并逐渐淡去。改动之后选「Balanced」预设即可恢复。

在深色纸上，台灯还会自己加上光：按同一物理模型算出、被照亮的纸面本身，温暖而幽暗，周围带柔和的光晕；分辨率足够细，光束收向灯泡处不会出现台阶，亮度控制在最亮处墨色对比度仍不低于 4.5:1。台灯会在离它最近的角落洒下一点暖光；月光穿过一扇由方形窗格组成的端正窗户（默认横三竖二），窗棂边缘柔和，四周是蓝色的夜影。

## Studio 中的设置

| 控件 | 作用 |
| --- | --- |
| Lamp | 开关台灯（与拉绳相同） |
| Pull cord | 显示或隐藏拉绳 |
| Preset | 预设：Off、Balanced、Cinematic |
| Light | 光源：Theme（跟随主题）、Carriage（字车灯）、Desk lamp（台灯）或 Window（窗外月光），与主题无关 |
| Brightness | 亮度：照到纸上的光有多强 |
| Beam angle | 光束角度：光锥张开的宽度，20° 到 160° |
| Beam | 光束形状：Pointed（默认）光锥收拢到灯泡成尖角；Soft 在灯泡周围柔和地展开，像大灯泡那样 |
| Aim | 朝向：台灯左右转动，最多 45° |
| Panes across、Panes down | 窗格：横向和纵向各 1 到 6 格（仅月光） |
| Slant | 倾斜：0° 时窗户端正；两边各可倾斜到 35°，像低角度侧光那样（仅月光） |
| Across the page、Down the page | 窗光落在纸上的横向和纵向位置（仅月光） |
| Reach | 照射距离：灯光往纸面上方照多远；月光时是窗格的大小 |
| Softness | 柔和度：光束边缘，或窗户和窗棂的边缘过渡有多柔和 |
| Dust in the beam | 光束中飘动的浮尘 |
| Film grain | 纸面上的细微颗粒；超过 20% 时会像胶片一样闪动 |
