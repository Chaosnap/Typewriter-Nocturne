# 台灯与拉绳

## 拉一下绳子

一根细长的绳子从房间顶部边缘垂下来，像剧院帷幕的拉绳：深红丝绳缠着金线，末端是鎏金流苏，有雕花的铃形罩和一圈散开的丝穗。往下拉就能开关台灯：拉动时绳子会伸长，拉到底时开关“咔哒”一声，松手后绳子回弹、摆动；流苏的每一根丝线都各自摆动，比绳子稍慢半拍。点击绳子，或在它获得键盘焦点时按 <kbd>Enter</kbd>，也会拉一下。用 View 菜单或快捷键开关台灯时，绳子也会轻轻晃动。

Studio 的 Lamp 一栏里的「Pull cord」可以显示或隐藏拉绳。专注模式下拉绳永远不会出现。

## 灯光

每个主题有自己的光源：

| 主题 | 光源 |
| --- | --- |
| Paper & Ink | 字架上的小灯，从字头处向纸面上方照射 |
| Midnight Study | 纸张右上方的台灯 |
| Moonlit Poetry | 穿过窗框洒落的月光 |

灯光遵循物理规律：照度随距离平方衰减，符合朗伯余弦定律，光锥边缘柔和；月光以平行光入射，并投下窗棂的影子。纸张按「反照率 × 照度」着色，所以墨色和纸色一起变亮变暗。远离灯光处房间会让纸面变暗，但墨色对比度永远不会低于 4.5:1。靠近灯泡处光锥柔和地展开，最亮的地方纸面纹理会被压平，所以灯正下方的文字和其他地方一样清晰。

## Studio 中的设置

| 控件 | 作用 |
| --- | --- |
| Lamp | 开关台灯（与拉绳相同） |
| Pull cord | 显示或隐藏拉绳 |
| Preset | 预设：Off、Balanced、Cinematic |
| Brightness | 亮度：照到纸上的光有多强 |
| Beam angle | 光束角度：光锥张开的宽度，20° 到 160° |
| Aim | 朝向：台灯左右转动，最多 45° |
| Reach | 照射距离：灯光往纸面上方照多远 |
| Softness | 柔和度：光束边缘过渡有多柔和 |
| Dust in the beam | 光束中飘动的浮尘 |
| Film grain | 纸面上的细微颗粒；超过 20% 时会像胶片一样闪动 |
