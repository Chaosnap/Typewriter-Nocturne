# 音效与输入法

所有声音都在应用启动时一次性合成，按键时只是播放一段短缓冲，永远不会延迟输入。声音按字头位置做立体声定位，并带一点房间混响。

| 你按下 | 你听到 |
| --- | --- |
| 字母、数字或符号 | 打字杆敲击滚筒 |
| <kbd>Space</kbd> | 空格键与擒纵机构 |
| <kbd>Enter</kbd> | 换行棘轮、字车回位与边距挡块 |
| <kbd>↑</kbd> <kbd>↓</kbd>（翻历史命令） | 滚筒旋钮转动一格，屏幕上的滚筒也会转动 |
| <kbd>←</kbd> <kbd>→</kbd> | 擒纵机构的一齿 |
| <kbd>Tab</kbd> | 制表器滑到挡位 |
| <kbd>Backspace</kbd>、<kbd>Delete</kbd> | 较轻的退格声 |
| 接近右边距 | 边距铃 |
| 拉台灯绳 | 拉链声与开关的“咔哒”声 |
| 打印诗笺 | 卷纸声、逐行打字声、按下火漆印的声音 |

<kbd>Ctrl</kbd> <kbd>C</kbd>、<kbd>⌘</kbd> <kbd>V</kbd> 这类快捷键不会击键。

## 输入法

拼音、假名、韩文等输入法和在任何终端里一样工作：候选窗口、组合中的文字以及 Shell 实际收到的内容都不受影响。它们同样有打字机反馈：

- 组合内容每变化一次（`n` → `ni` → `nih` …）都会击键一次，字头也会动；
- 选择或翻页候选词是一声轻敲；
- 上屏时是一记有力的双击，上屏的文字在 Shell 显示出来后也会有打字墨迹。

## 设置

Studio 里有四种音色（*Standard*、*Portable*、*Electric*、*Whisper*）、*Volume*（音量）、*Margin bell*（边距铃）和声音总开关；也可以用 View 菜单或快捷键开关声音。
