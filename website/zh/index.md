features:
  - title: 首先是真正的终端
    details: Hyper 的终端、xterm.js 和 node-pty 运行你真实的 Shell。退出码、括号粘贴、输入法和全屏程序都按原样工作。
    link: /zh/guide/stage
  - title: 3D 建模的打字机
    details: 压纸滚筒、压纸杆、珐琅机身、色带卷轴、镍制标尺和鎏金铭牌，基于物理的材质与柔和阴影。
    link: /zh/guide/stage
  - title: 按物理规律移动的字头
    details: 齿条每一齿对应一列，擒纵机构推动前进，停下时绕支点摆动，每次击键都朝滚筒敲击。
    link: /zh/guide/stage
  - title: 符合物理的灯光
    details: 平方反比衰减、朗伯余弦定律、柔边光锥、穿过窗格的月光，用一根编织拉绳开关。
    link: /zh/guide/lamp
  - title: 纸与墨
    details: 从棉纸到羊皮纸共六种纸张。刚打出的字墨迹更重，然后沉淀为印刷字。
    link: /zh/guide/paper
  - title: 机器的声音
    details: 打字杆、字车回位、边距铃、翻历史命令时的滚筒棘轮、制表器，按字头位置立体声定位。
    link: /zh/guide/sounds
  - title: 支持输入法
    details: 拼音、假名、韩文在组合输入时就会击键；上屏时是一记有力的双击。
    link: /zh/guide/sounds
  - title: 自选字体，自带 Nerd Font 图标
    details: 内置字体、Nerd Font 预设、任意已安装字体，每种字体都能显示 Nerd Font 图标。
    link: /zh/guide/type
  - title: 印刷机
    details: 把代码片段或终端内容印成十四行诗式的诗笺，盖上红色火漆印，存入档案。
    link: /zh/guide/press
