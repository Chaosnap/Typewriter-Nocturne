# Privacy and security

- **The terminal stream is never touched.** The effects never subscribe to, delay, buffer or rewrite what goes
  to or comes from your shell. Keys are observed passively, without stopping or changing them, so shortcuts,
  paste, bracketed paste and input methods behave as in Hyper.
- **Hidden input stays hidden.** A type impression is only drawn for a character the terminal has already
  displayed; passwords typed without echo never appear in any effect.
- **Terminal text is read only when you print it.** The Press reads the selection or the screen only when you
  choose *Selection* or *Screen*. Folios are kept on your computer only, and nothing is uploaded anywhere.
- **Everything is validated.** Settings and folios are checked before they are used or written; file names in
  the Archive are generated by the app, never taken from input; an exported image must be a PNG. Themes
  contain no code.
- **Your system is left alone.** Shell start-up files are never modified, and an existing Hyper installation is
  never read or changed.
- **Electron's boundaries are kept as in Hyper.** The bundled fonts are fetched only at build time, pinned to a
  release and verified by hash; nothing is downloaded on your computer.
