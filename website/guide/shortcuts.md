# Shortcuts

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| Focus Mode | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>Enter</kbd> | <kbd>Ctrl</kbd> <kbd>⇧</kbd> <kbd>Enter</kbd> |
| Lamp on / off | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>L</kbd> | <kbd>Ctrl</kbd> <kbd>⇧</kbd> <kbd>L</kbd> |
| Nocturne Studio | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>,</kbd> | <kbd>Ctrl</kbd> <kbd>⇧</kbd> <kbd>,</kbd> |
| Typewriter sound on / off | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>M</kbd> | <kbd>Ctrl</kbd> <kbd>Alt</kbd> <kbd>M</kbd> |
| The Press | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>P</kbd> | <kbd>Ctrl</kbd> <kbd>⇧</kbd> <kbd>P</kbd> |
| The Archive | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>O</kbd> | <kbd>Ctrl</kbd> <kbd>⇧</kbd> <kbd>O</kbd> |

All of them are also in the **View** menu. Every other shortcut is Hyper's (new tab, split pane, search,
zoom…). Any of them can be changed in `hyper.json` under `keymaps`, for example:

```json
{
  "keymaps": {
    "nocturne:print": "ctrl+alt+p"
  }
}
```
